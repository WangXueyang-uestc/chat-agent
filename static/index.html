⚙️ 设置

配置 LLM API 参数，支持 DeepSeek、OpenAI、Gemini、Claude 等兼容 OpenAI API 的模型

LLM API 配置

例如：https://api.deepseek.com/v1 或 https://api.openai.com/v1
例如：deepseek-chat, gpt-4, gpt-3.5-turbo, claude-3-sonnet 等
API Key 将保存在本地配置文件中
允许模型访问最新网络信息（需要模型支持，如 DeepSeek-R1、某些 GPT-4 版本等）
启用深度推理能力（需要推理模型支持，如 deepseek-reasoner、deepseek-r1 等）

支持的模型

  • DeepSeek: Base URL: https://api.deepseek.com/v1, Model: deepseek-chat, deepseek-reasoner, deepseek-r1
  • OpenAI: Base URL: https://api.openai.com/v1, Model: gpt-4, gpt-3.5-turbo, gpt-4-turbo
  • 元宝API: Base URL: 根据元宝API提供的地址配置, Model: 根据元宝API提供的模型名称配置（完全兼容 OpenAI API 格式）
  • 其他兼容 OpenAI API 的服务: 使用对应的 Base URL 和 Model 名称

高级功能说明

  • 联网搜索: 允许模型访问最新网络信息。支持此功能的模型包括 DeepSeek-R1、某些 GPT-4 版本等。启用后，模型可以获取实时信息。
  • 深度思考/推理模式: 启用深度推理能力，适合复杂问题分析。推荐使用专门的推理模型，如 deepseek-reasoner、deepseek-r1 等。

⚠️ 请注意：API Key 会保存在本地配置文件中，请妥善保管。高级功能需要模型本身支持，不是所有模型都支持联网搜索和深度思考。
